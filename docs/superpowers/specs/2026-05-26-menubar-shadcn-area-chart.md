## Why this slice

Tremor was the wrong tool for this codebase. Three reasons surfaced post-smoke-test:

1. **Theming friction.** Mapping Tremor's `tremor.brand/background/content` slots to DESIGN.md tokens required a separate Tailwind theme extension (~30 LOC) that lives in parallel to the project's existing CSS-var-based theming. shadcn's chart pattern uses CSS vars directly — the same mechanism the rest of `packages/ui/src/components/ui/` already uses.
2. **Bundle weight.** Tremor pulls in Recharts + d3 + its own wrapper layer (~125KB gzipped). shadcn primitives are ~200 LOC of source we own, with only Recharts as the engine (~75KB gzipped). Net: ~−50KB.
3. **Project pattern fit.** `packages/ui/src/components/ui/` already houses shadcn-style components (button, card, dialog, dropdown-menu, etc.) generated via `pnpm dlx shadcn@latest add ...`. The chart primitives belong in the same place using the same install flow.

This slice **reverts the Tremor library swap only** — the structural improvements approved during smoke-test (16-week unified scope, stable-height wrapper, jsdom Recharts mock, `MMM D` date label format, `iso` field for tooltip lookup, `SessionMapContext` pattern) all survive because they're library-agnostic.

## Installation procedure

shadcn's CLI is already configured for this workspace — `packages/ui/components.json` declares the ui alias, Tailwind config path, and `cssVariables: true`.

```bash
# Run from inside packages/ui (where components.json lives):
pnpm dlx shadcn@latest add chart
```

This command:
- Installs `recharts` (v3, the engine) as a peer-friendly dep — added to `packages/ui/package.json` automatically
- Generates `packages/ui/src/components/ui/chart.tsx` containing the primitives (`ChartContainer`, `ChartTooltip`, `ChartTooltipContent`, `ChartLegend`, `ChartLegendContent`, and the `ChartConfig` type)
- Does NOT modify `globals.css` directly — the user adds chart CSS vars manually in a follow-up step

## CSS variable — monochrome chart palette

Add to `packages/ui/src/globals.css` inside the `:root` block (alongside existing `--bg-marketing`, `--text-primary`, etc.):

```css
/* shadcn chart palette — single monochrome slot for v0.1.
   DESIGN.md L40: "Pure monochrome — zero chromatic colors". */
--chart-1: 220 14% 96%;  /* hsl() form of #f7f8f8 (Primary text token) */
```

shadcn's CSS-var convention is HSL channels without the `hsl()` wrapper, so consumers can write `hsl(var(--chart-1) / 0.12)` to control alpha at usage sites. The hex `#f7f8f8` corresponds to roughly `hsl(220, 14%, 96%)` — matches DESIGN.md L47.

If we ever add a second series (deferred), add `--chart-2: 220 9% 46%;` (≈ `#62666d`, DESIGN.md Quaternary).

## `<DualLineChart>` after the rewrite

Library-agnostic structure preserved:

- Props unchanged: `{ tokens: HeatmapPoint[]; sessions: HeatmapPoint[] }`
- `chartData`: each row has `date` (display label, formatted via `shortLabel`), `iso` (raw ISO date for tooltip lookup), `tokens` (numeric value)
- `sessionMap`: `Map<isoDate, sessionsCount>`
- `SessionMapContext` carries `sessionMap` so the tooltip component lives at module scope (preserves the ESLint compliance we landed in the Tremor pass)

Library-specific surface (the rewrite):

```tsx
import { Area, AreaChart, CartesianGrid, XAxis, YAxis } from 'recharts'
import { ChartContainer, ChartTooltip, type ChartConfig } from '@/components/ui/chart'

const chartConfig = {
  tokens: { label: 'Tokens', color: 'hsl(var(--chart-1))' },
} satisfies ChartConfig

// Inside the component, replacing the Tremor LineChart:
return (
  <SessionMapContext.Provider value={sessionMap}>
    <ChartContainer
      config={chartConfig}
      className="h-[140px] w-full"
      style={{ fontFamily: MONO }}
    >
      <AreaChart
        accessibilityLayer
        data={chartData}
        margin={{ left: 0, right: 8, top: 8, bottom: 0 }}
      >
        <CartesianGrid
          vertical={false}
          stroke="var(--border-default)"
          strokeDasharray="3 3"
        />
        <XAxis
          dataKey="date"
          tickLine={false}
          axisLine={false}
          tickMargin={6}
          interval="preserveStartEnd"
          tick={{ fontSize: 9, fill: 'var(--text-quaternary)' }}
        />
        <YAxis
          tickLine={false}
          axisLine={false}
          width={36}
          tickFormatter={formatTokens}
          tick={{ fontSize: 9, fill: 'var(--text-quaternary)' }}
        />
        <ChartTooltip
          cursor={{ stroke: 'var(--border-default)' }}
          content={ChartTooltip}
        />
        <Area
          dataKey="tokens"
          type="natural"
          stroke="var(--color-tokens)"
          fill="var(--color-tokens)"
          fillOpacity={0.12}
          strokeWidth={1.5}
          dot={false}
        />
      </AreaChart>
    </ChartContainer>
  </SessionMapContext.Provider>
)
```

Key details:
- `var(--color-tokens)` is automatically emitted by `<ChartContainer>` from the `chartConfig.tokens.color` value. shadcn pattern; we don't define this CSS var ourselves.
- `fillOpacity={0.12}` produces the filled-area-below-the-line aesthetic without dominating the chart. Monochrome (white at 12% alpha over dark popover bg).
- `type="natural"` produces a smooth curve. Matches shadcn area-chart docs default.
- `dot={false}` keeps the line clean; the cursor crosshair on hover provides the per-point feedback.
- The existing `ChartTooltip` inline component (the 2-line custom one we already have) becomes the `content` prop. Same custom JSX, swap `customTooltip` (Tremor's prop name) → `content` (shadcn/Recharts prop name).

## ChartTooltip custom content

Adapt the existing tooltip component to shadcn/Recharts payload shape:

```tsx
interface RechartsTooltipProps {
  active?: boolean
  payload?: Array<{ value: number; payload: ChartRow }>
}

function ChartTooltip({ active, payload }: RechartsTooltipProps) {
  const sessionMap = useContext(SessionMapContext)
  if (!active || !payload?.[0]) return null
  const row = payload[0].payload
  const tokensVal = Number(payload[0].value ?? 0)
  const sessionsVal = sessionMap.get(row.iso) ?? 0
  return (
    <div
      className="rounded border border-[var(--border-default)] bg-[var(--surface-overlay)] px-2 py-1.5 text-[11px] shadow-md"
      style={{ fontFamily: MONO }}
    >
      <div className="text-[var(--text-primary)]">
        {sessionsVal} sessions · {formatTokens(tokensVal)} tokens
      </div>
      <div className="text-[10px] text-[var(--text-tertiary)]">
        {longDate(row.iso)}
      </div>
    </div>
  )
}
```

Same shape we had under Tremor — DESIGN.md L211 spec: Berkeley Mono, surface-overlay bg, border-default, primary text on top line, tertiary date 10px below.

Note: the prop name in `<ChartTooltip content={...}>` is for Recharts' Tooltip primitive (re-exported by shadcn's `ChartTooltip`). The custom component receives Recharts' standard tooltip props.
