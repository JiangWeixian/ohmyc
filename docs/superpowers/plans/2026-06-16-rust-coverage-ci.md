# Rust Coverage CI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add non-blocking `crates/ohmyc-core` Rust coverage visibility in CI and provide memorable local `cargo` aliases for the same report.

**Architecture:** Keep the existing workspace Rust checks intact, ignore local generated coverage artifacts, then add `cargo-llvm-cov` as a post-test reporting step scoped to the `ohmyc-core` package. Local coverage uses native cargo aliases in `.cargo/config.toml`, while CI uploads `lcov.info` plus HTML output and writes the textual coverage table into `$GITHUB_STEP_SUMMARY`.

**Tech Stack:** Rust workspace, Cargo aliases, `.gitignore`, `cargo-llvm-cov`, GitHub Actions, `taiki-e/install-action`, `actions/upload-artifact`.

## Task 3: Add Non-Blocking ohmyc-core Coverage to Rust CI

**Files:**
- Modify: `.github/workflows/ci-rust.yml`

- [ ] **Step 1: Inspect the current workflow before editing**

- [ ] **Step 2: Update the workflow**

Replace `.github/workflows/ci-rust.yml` with:

```yaml
name: Rust CI

on:
  push:
  pull_request:
    branches: [master, release]

jobs:
  rust-check:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v5
      - name: Install system dependencies
        run: |
          sudo apt-get update
          sudo apt-get install -y libgtk-3-dev libwebkit2gtk-4.1-dev libappindicator3-dev librsvg2-dev patchelf libglib2.0-dev libssl-dev
      - uses: dtolnay/rust-toolchain@stable
        with:
          components: rustfmt, clippy, llvm-tools
      - uses: Swatinem/rust-cache@v2
      - uses: taiki-e/install-action@cargo-llvm-cov
      - run: cargo fmt --all -- --check
      - run: cargo clippy --all-targets --all-features -- -D warnings
      - run: cargo test --all
      - name: Generate ohmyc-core lcov coverage
        run: cargo llvm-cov -p ohmyc-core --lcov --output-path lcov.info
      - name: Add ohmyc-core coverage summary
        run: cargo llvm-cov report -p ohmyc-core >> "$GITHUB_STEP_SUMMARY"
      - name: Generate ohmyc-core HTML coverage
        run: cargo llvm-cov report -p ohmyc-core --html --output-dir cov-html
      - name: Upload ohmyc-core coverage artifact
        uses: actions/upload-artifact@v4
        with:
          name: ohmyc-core-coverage
          path: |
            lcov.info
            cov-html/html/
```

Notes for the implementer:
- Keep `cargo test --all`; it remains the full workspace regression check.
- The coverage steps run after tests and use the default `if: success()` behavior.
- Do not add `--fail-under-*` flags.
- Do not add Codecov or PR comment actions.
- Do not add a separate job.
- Do not change workflow triggers.
