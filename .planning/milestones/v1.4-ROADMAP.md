# Roadmap: v1.4 Project-Aware Loading + .cu Rebrand

**Shipped:** 2026-04-19
**Phases:** 10-12
**Status:** Complete

## Key Accomplishments

1. **ConfigLocator 集中路径解析** — 所有 `.claude`/`.cui` 路径通过单一服务，零散落字面量
2. **Project-local 双源加载** — API 返回 global + project 合并结果，project 优先，source 标签区分来源
3. **SourceBadge project variant** — 绿色视觉标识 project-scoped 组件
4. **写入路径重品牌为 ~/.cui/** — 管理数据写 `~/.cui/`，插件读 `~/.claude/`，`CUI_HOME` 可独立覆盖写入路径
5. **UAT 发现并修复 CUI_HOME/AGENT_HOME 独立性问题** — UAT 中发现 AGENT_HOME 错误覆盖 writeBaseDir，已修复为 CUI_HOME 独立控制

## Phase Details

### Phase 10: Config Foundation

**Goal**: All path resolution goes through a single ConfigLocator service, project directories are discoverable at startup, and the UI can render project-scoped source badges.

**Plans:**
- [x] 10-01-PLAN — ConfigLocator service with project discovery and path centralization (FOUND-01, FOUND-02)
- [x] 10-02-PLAN — SourceBadge project variant and shared schema source enum extension (FOUND-03)

**Duration:** 4 min | **Files:** 9 | **Tests:** 283 CLI + 51 UI

### Phase 11: Project-Local Loading

**Goal**: Users see both global and project-scoped components merged in every inventory view, with source badges distinguishing origin and project items taking precedence on conflicts.

**Plans:**
- [x] 11-01-PLAN — Backend dual-source loading with scope field and merge routes (LOAD-01, LOAD-02, LOAD-03)
- [x] 11-02-PLAN — Frontend merge display and view-only behavior for project items (LOAD-02)

**Duration:** 8 min | **Files:** 19 | **Tests:** 298 CLI + 51 UI

### Phase 12: .cu Rebrand

**Goal**: All managed data writes go to `~/.cui/` instead of `~/.claude/`, while existing data in `~/.claude/` remains on disk and plugins stay readable from `~/.claude/plugins/`.

**Plans:**
- [x] 12-01-PLAN — ConfigLocator write path rebrand with split writeBaseDir/claudeCodeDir (REBR-01, REBR-02)

**Duration:** 4 min | **Files:** 2 | **Tests:** 18 ConfigLocator + 305 full suite

**UAT:** 6 tests passed, 1 issue found and fixed inline (CUI_HOME/AGENT_HOME independence)
