## Phase Details

### Phase 4: Explorer Tab Corrections
**Goal**: Explorer tabs show accurate, source-distinguished data and only expose implemented features
**Depends on**: Phase 3 (shipped v1.0)
**Requirements**: TAB-01, TAB-02, TAB-03, TAB-04, PLUG-01
**Success Criteria** (what must be TRUE):
  1. Hooks tab shows each entry with a "local" badge (from settings.json) or "plugin" badge with plugin name (from plugin contributions)
  2. MCP Servers tab shows each entry with a "local" badge (from .mcp.json) or "plugin" badge with plugin name (from plugin contributions)
  3. LSP Servers tab shows each entry with a "local" badge (from .lsp.json) or "plugin" badge with plugin name (from plugin contributions)
  4. CLAUDE.md tab is not visible in the Explorer sidebar
  5. Plugins tab displays which profiles reference each plugin by name
**Plans**: 2 plans

Plans:
- [x] 04-01-PLAN.md -- Backend API plugin merging with source attribution for hooks/MCP/LSP configs
- [x] 04-02-PLAN.md -- Frontend source badges, CLAUDE.md tab removal, plugin profile references
