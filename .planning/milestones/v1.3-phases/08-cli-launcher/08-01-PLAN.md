<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI runtime → filesystem | Untrusted local filesystem state influences which asset directory is served |
| Browser → Fastify static server | Untrusted HTTP requests can probe asset paths and SPA fallback behavior |
| CLI launcher → network port binding | Local environment may already occupy requested ports or expose server unexpectedly |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-01 | T | `packages/cli/src/server/index.ts` asset-root resolution | mitigate | Resolve only explicit packaged/workspace candidate directories, require `index.html` existence before registering static serving, and throw a descriptive startup error for invalid roots. |
| T-08-02 | I | SPA/static serving | mitigate | Keep API routes registered before fallback and use Fastify static root boundaries so arbitrary filesystem paths are not exposed through request URLs. |
| T-08-03 | D | `startServer()` port selection | mitigate | Use `get-port` fallback sequence and return the selected port so launcher logic can open the correct URL instead of retrying blindly on a blocked port. |
| T-08-04 | E | Fastify listen host binding | accept | Retain current local-app hosting model for MVP; Phase 8 focuses on launcher correctness, not auth or LAN restriction changes. |
</threat_model>
