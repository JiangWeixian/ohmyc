    1. Remove the claude-md entry from SECTIONS array:
       Delete the entire line: `{ id: 'claude-md', label: 'CLAUDE.md', icon: FileText },`
       Do NOT remove renderPlaceholder or the activeSection === 'claude-md' check.

    2. Update count variables from Object.keys to .length:
       Change `Object.keys(hooks ?? {}).length` to `(hooks ?? []).length`
       Change `Object.keys(mcpServers ?? {}).length` to `(mcpServers ?? []).length`
       Change `Object.keys(lspServers ?? {}).length` to `(lspServers ?? []).length`

       ```typescript
       data: hooks?.map(h => ({ ...h, config: h.data })),
       ```
       For MCP and LSP, pass the array data directly since they already use the ConfigEntry shape.

    4. Add useProfiles to Explorer component:
       ```typescript
       const { data: profilesData } = useProfiles();
       ```
       Import useProfiles from hooks/useProfiles if not already imported.

    5. Inside renderPlugins, build the plugin reference map:
       ```typescript
       const allProfiles = profilesData?.profiles ?? [];
       const pluginRefMap = useMemo(() => {
         const map = new Map&lt;string, string[]&gt;();
         for (const p of allProfiles) {
           for (const pluginId of p.plugins) {
             const existing = map.get(pluginId) ?? [];
             existing.push(p.name);
             map.set(pluginId, existing);
           }
         }
         return map;
       }, [allProfiles]);
       ```
       Add useMemo to the react import.
