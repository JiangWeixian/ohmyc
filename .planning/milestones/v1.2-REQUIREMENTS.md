# Requirements: ClaudeUI

**Defined:** 2026-04-08
**Core Value:** Users can reliably assemble and switch between Claude-focused coding environments from reusable local components without manually editing scattered config files.

## v1 Requirements (Current: v1.2)

### Store -- Model Configs

- [x] **STORE-06**: User can create a model config with name, API key, base URL, model name, and provider fields
- [x] **STORE-07**: User can edit an existing model config's fields
- [x] **STORE-08**: User can delete a model config (blocked if referenced by a profile)
- [x] **STORE-09**: User sees model configs listed in the store UI alongside agents, skills, and commands
- [x] **STORE-10**: API key is masked in list and edit views (only last 4 characters visible)
- [x] **STORE-11**: Base URL is validated as a proper URL format, model name is validated against known aliases

### Profile Integration

- [x] **PROF-05**: User can select exactly one model config in the profile editor via a picker
- [x] **PROF-06**: Profile detail view shows the assigned model config name and key fields
- [x] **PROF-07**: User cannot delete a model config that is referenced by any profile

### Activation

- [x] **ACTV-03**: Activating a profile with a model config writes ANTHROPIC_API_KEY, ANTHROPIC_BASE_URL, ANTHROPIC_MODEL, and provider flags to settings.json env field
- [x] **ACTV-04**: Deactivating a profile removes model-related env vars from settings.json and restores previous values
- [x] **ACTV-05**: Preflight check shows which environment variables the model config will set or change before activation

## v2 Requirements

Deferred to future release. Tracked but not in current roadmap.

### Multi-Ecosystem

- **MULTI-01**: Import and convert components from other coding-agent ecosystems into Claude-centered model

## Out of Scope

| Feature | Reason |
|---------|--------|
| Multiple model configs per profile | Adds complexity without clear use case -- one model config per profile is sufficient |
| Real-time model config switching without profile reactivation | Requires runtime Claude Code integration beyond v1.2 scope |
| API key encryption at rest | Important but deferred -- store is local filesystem, user-controlled |
| Import model configs from external directories | Not a core workflow -- users create configs manually via form |
