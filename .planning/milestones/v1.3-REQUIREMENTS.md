# Requirements: ClaudeUI

**Defined:** 2026-04-13
**Core Value:** Users can reliably assemble and switch between Claude-focused coding environments from reusable local components without manually editing scattered config files.

## v1.3 Requirements

Requirements for CLI MVP release. Each maps to roadmap phases.

### CLI Startup

- [ ] **CLI-01**: User can run `cu` from terminal to start the application
- [ ] **CLI-02**: CLI serves pre-built UI static assets bundled into the package (no runtime build)
- [ ] **CLI-03**: CLI starts the Fastify server and auto-opens the browser to the UI
- [ ] **CLI-04**: CLI shows startup status (starting server, opening browser)
- [ ] **CLI-05**: CLI handles port conflicts gracefully (auto-select available port)

### Packaging

- [ ] **PKG-01**: `cu` is installable globally via `npm install -g` (or equivalent)
- [ ] **PKG-02**: Package includes built CLI and UI assets ready to run without build step
- [ ] **PKG-03**: CLI works after global install without additional setup or dev dependencies

## v2 Requirements

Deferred to future release. Tracked but not in current roadmap.

### Directory Rebrand

- **DIR-01**: AGENT_HOME default changes from `.claude` to `.cu`
- **DIR-02**: Existing users can migrate data from `~/.claude/` to `~/.cu/` seamlessly

### CLI Enhancements

- **ENH-01**: CLI auto-update mechanism
- **ENH-02**: CLI configuration file for default port, browser preference, etc.
- **ENH-03**: `cu dev` mode for development with hot reload

## Out of Scope

| Feature | Reason |
|---------|--------|
| Directory rebrand (.claude -> .cu) | AGENT_HOME stays .claude for v1.3 |
| CLI update mechanism | MVP -- users reinstall for updates |
| Configuration file for CLI | MVP -- env vars and defaults sufficient |
| Cross-agent ecosystem support | Deferred -- focus on Claude workflows |
