- `--card` = `#0f1112` → `hsl(180, 4%, 6%)` → `180 4% 6%` (matches --surface-raised)
- `--card-foreground` = same as --foreground
- `--popover` = `#15181a` → `hsl(195, 5%, 9%)` → `195 5% 9%` (matches --surface-overlay)
- `--popover-foreground` = same as --foreground
- `--primary` = `#5E6AD2` → `hsl(233, 54%, 60%)` → `233 54% 60%` (matches --accent-blue)
- `--primary-foreground` = `#ffffff` → `hsl(0, 0%, 100%)` → `0 0% 100%` (white text on blue)
- `--secondary` = approx `#1a1d20` → `hsl(200, 4%, 13%)` → `200 4% 13%` (slightly raised surface)
- `--secondary-foreground` = same as --foreground
- `--muted` = same as --secondary (muted background = raised surface)
- `--muted-foreground` = `#b2b5b7` → `hsl(200, 5%, 60%)` → `200 5% 60%` (matches --text-secondary approximately, actual is closer to 70% lightness but 60% provides better contrast for "muted" text)

Replace the entire tailwind.config.js with:

```javascript
/** @type {import('tailwindcss').Config} */
export default {
  content: [
    "./index.html",
    "./src/**/*.{js,ts,jsx,tsx}",
  ],
  theme: {
    extend: {
      colors: {
        background: "hsl(var(--background))",
        foreground: "hsl(var(--foreground))",
        card: {
          DEFAULT: "hsl(var(--card))",
          foreground: "hsl(var(--card-foreground))",
        },
        popover: {
          DEFAULT: "hsl(var(--popover))",
          foreground: "hsl(var(--popover-foreground))",
        },
        primary: {
          DEFAULT: "hsl(var(--primary))",
          foreground: "hsl(var(--primary-foreground))",
        },
        secondary: {
          DEFAULT: "hsl(var(--secondary))",
          foreground: "hsl(var(--secondary-foreground))",
        },
        muted: {
          DEFAULT: "hsl(var(--muted))",
          foreground: "hsl(var(--muted-foreground))",
        },
        accent: {
          DEFAULT: "hsl(var(--accent))",
          foreground: "hsl(var(--accent-foreground))",
        },
        destructive: {
          DEFAULT: "hsl(var(--destructive))",
          foreground: "hsl(var(--destructive-foreground, var(--foreground)))",
        },
        border: "hsl(var(--border))",
        input: "hsl(var(--input))",
        ring: "hsl(var(--ring))",
      },
      borderRadius: {
        lg: "var(--radius)",
        md: "calc(var(--radius) - 2px)",
        sm: "calc(var(--radius) - 4px)",
      },
    },
  },
  plugins: [
    require("tailwindcss-animate"),
  ],
}
```

Key points:
- Each color uses the `hsl(var(--token))` pattern that shadcn expects
- Nested color objects (card, popover, primary, secondary, muted, accent, destructive) have DEFAULT + foreground
- `destructive-foreground` uses a fallback to `--foreground` since we didn't define it in CSS (it's typically white/light)
- borderRadius unchanged from current config
- tailwindcss-animate plugin retained
