  <name>Task 1: Initialize shadcn and install base primitives</name>
  <files>packages/ui/components.json, packages/ui/src/lib/utils.ts, packages/ui/tsconfig.json, packages/ui/vite.config.ts</files>

  <action>
1. **Ensure tsconfig.json has path aliases.** Check if `packages/ui/tsconfig.json` exists. If it has no `paths` config, add:
   ```json
   "baseUrl": ".",
   "paths": { "@/*": ["./src/*"] }
   ```

2. **Ensure vite.config.ts has resolve alias.** Check if `packages/ui/vite.config.ts` has `resolve.alias` for `@`. If not, add:
   ```typescript
   import path from 'path'
   resolve: { alias: { '@': path.resolve(__dirname, './src') } }
   ```

3. **Run shadcn init** in packages/ui directory. This auto-detects Vite, React, Tailwind and creates `components.json`:
   ```bash
   cd packages/ui && npx shadcn@latest init --defaults
   ```
   IMPORTANT: After init, review `components.json` and fix these settings:
   - `"tsx"` should be `true` (we use TypeScript)
   - `"aliases.components"` should be `"@/components"` (not `@claudeui/shared/components`)
   - `"aliases.ui"` should be `"@/components/ui"`
   - `"aliases.utils"` should be `"@/lib/utils"`
   - `"aliases.lib"` should be `"@/lib"`
   - `"aliases.hooks"` should be `"@/hooks"`

   If `npx shadcn@latest init` fails due to pnpm store mismatch, create `components.json` manually:
   ```json
   {
     "$schema": "https://ui.shadcn.com/schema.json",
     "style": "new-york",
     "rsc": false,
     "tsx": true,
     "tailwind": {
       "config": "tailwind.config.js",
       "css": "src/globals.css",
       "baseColor": "neutral",
       "cssVariables": true,
       "prefix": ""
     },
     "iconLibrary": "lucide",
     "aliases": {
       "components": "@/components",
       "utils": "@/lib/utils",
       "ui": "@/components/ui",
       "lib": "@/lib",
       "hooks": "@/hooks"
     }
   }
   ```
   Then manually install the required peer deps: `pnpm add class-variance-authority clsx tailwind-merge lucide-react @radix-ui/react-slot tailwindcss-animate`

4. **Ensure `packages/ui/src/lib/utils.ts` exists.** This is the `@/lib/utils` path that both shadcn and uitripled components import from. Content:
   ```typescript
   import { clsx, type ClassValue } from "clsx"
   import { twMerge } from "tailwind-merge"
   export function cn(...inputs: ClassValue[]) {
     return twMerge(clsx(inputs))
   }
   ```
   If the existing `packages/ui/src/components/cn.ts` already exports the same function, keep it — existing components still import from it. The new `@/lib/utils.ts` serves shadcn + uitripled components.

5. **Install shadcn base primitives.** Run in packages/ui:
   ```bash
   cd packages/ui && npx shadcn@latest add button card badge input textarea select switch tabs dialog dropdown-menu tooltip label separator scroll-area avatar slider checkbox --yes --overwrite
   ```
   This installs to `src/components/ui/`. Each file uses `import { cn } from "@/lib/utils"` and Radix UI imports.

   If the shadcn CLI fails (pnpm store issue), copy each primitive manually from `vendor/uitripled/packages/components/react-shadcn/src/ui/` to `src/components/ui/`, removing `"use client"` directives.

6. **Run TypeScript check**: `cd packages/ui && npx tsc --noEmit` must pass.
