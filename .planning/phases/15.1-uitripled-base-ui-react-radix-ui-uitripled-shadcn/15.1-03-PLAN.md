## Key Migration Patterns

### Tabs-specific requirements
- Current has `variant` prop ("default" | "line") on TabsList with CVA
- Current has `orientation` prop on Tabs root
- Current uses complex CSS with `data-active`, `data-horizontal`, `data-vertical`, `group-data-[variant=line]`
- Radix Tabs uses `data-[state=active]` instead of `data-active`
- Radix TabsList doesn't have variant prop — must be handled via className or wrapper
- The `orientation` prop in current @base-ui affects layout; Radix Tabs also supports orientation

### Tooltip-specific requirements
- Current has `side`, `sideOffset`, `align`, `alignOffset` props on TooltipContent
- Current uses `data-[state=delayed-open]` for animation states
- Radix Tooltip uses `data-[state=instant-open]` and `data-[state=delayed-open]`
- Radix TooltipContent accepts `side`, `sideOffset`, `align` directly as props
- Must preserve arrow support (current has TooltipPrimitive.Arrow)
