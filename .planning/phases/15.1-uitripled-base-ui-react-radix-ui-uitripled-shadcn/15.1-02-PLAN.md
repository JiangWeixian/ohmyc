### ScrollArea Special Requirements (D-04, D-05)
- Use uitripled's approach: pure div with webkit scrollbar pseudo-elements
- Preserve ClaudeUI's scrollbar thumb/track colors using existing CSS custom properties
- Current @base-ui ScrollArea uses custom scrollbar thumb with `bg-border`
- Target: webkit scrollbar with `&[::-webkit-scrollbar-thumb]:bg-border` or similar
- The scroll-area is used in Sidebar and Explorer components

### State Attribute Mapping (Critical)
- @base-ui `data-checked` → Radix `data-[state=checked]`
- @base-ui `data-unchecked` → Radix `data-[state=unchecked]`
- @base-ui `data-disabled` → Radix `data-[disabled]`
- Radix Checkbox uses `data-[state=checked]` and `data-[state=unchecked]`
- Radix Switch uses `data-[state=checked]` and `data-[state=unchecked]`
- Radix Slider uses `data-[orientation=horizontal]` instead of `data-horizontal`

### Switch Size Support
- Current has `size` prop with "sm" | "default"
- Current uses `data-[size=default]` and `data-[size=sm]` attributes in CSS
- Radix Switch doesn't have built-in size support
- Must implement size using wrapper classes or data attributes
