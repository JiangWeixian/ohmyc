## Key Migration Patterns

### Dialog-specific requirements
- Current has `showCloseButton` prop on DialogContent (custom, not in Radix)
- Current uses `DialogPrimitive.Backdrop` for overlay; Radix uses `DialogPrimitive.Overlay`
- Current uses `DialogPrimitive.Popup` for content; Radix uses `DialogPrimitive.Content`
- Current uses `DialogPrimitive.Close` with `render` prop; Radix uses `DialogPrimitive.Close` as button
- Must preserve DialogFooter with `showCloseButton` prop support
- Must preserve all animation classes (data-open/data-closed → data-[state=open]/data-[state=closed])

### DropdownMenu-specific requirements
- Current uses @base-ui/react/menu (MenuPrimitive); target is @radix-ui/react-dropdown-menu
- Current has many sub-components: DropdownMenuSub, DropdownMenuSubTrigger, DropdownMenuSubContent, DropdownMenuCheckboxItem, DropdownMenuRadioGroup, DropdownMenuRadioItem
- Must preserve `inset` prop on several components
- Must preserve `variant` prop on DropdownMenuItem ("default" | "destructive")
- Must preserve `render` prop usage for indicators

### Select-specific requirements
- Current has complex positioning props (side, sideOffset, align, alignOffset, alignItemWithTrigger)
- Current uses `SelectPrimitive.Positioner` wrapper; Radix doesn't need it
- Current uses `SelectPrimitive.Popup`; Radix uses `SelectPrimitive.Content`
- Must preserve scroll up/down buttons
- Must preserve item text structure with flex layout
