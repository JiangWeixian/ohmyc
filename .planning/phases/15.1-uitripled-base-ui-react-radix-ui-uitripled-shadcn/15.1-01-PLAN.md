## Key Migration Patterns

### @base-ui → @radix-ui state attribute mapping
- @base-ui `data-checked` → Radix `data-[state=checked]`
- @base-ui `data-unchecked` → Radix `data-[state=unchecked]`
- @base-ui `data-open` → Radix `data-[state=open]`
- @base-ui `data-closed` → Radix `data-[state=closed]`
- @base-ui `data-active` → Radix `data-[state=active]`
- @base-ui `data-disabled` → Radix `data-[disabled]`

### Component-specific notes

**avatar.tsx:**
- Current: Uses `AvatarPrimitive.Root` from @base-ui/react/avatar
- Target: Use `@radix-ui/react-avatar` primitives (Root, Image, Fallback)
- Preserve: AvatarBadge, AvatarGroup, AvatarGroupCount (these are pure React additions not in uitripled)
- Preserve: `size` prop and data-size attributes
- Preserve: All data-slot attributes for test compatibility

**badge.tsx:**
- Current: Uses `useRender` and `mergeProps` from @base-ui/react
- Target: Pure React + cva (same as uitripled)
- Preserve: All variant definitions (default, secondary, destructive, outline, ghost, link)
- Preserve: `render` prop support if possible, or document if removed
- Note: uitripled badge only has 4 variants (no ghost, no link). Add them.

**button.tsx:**
- Current: Uses `ButtonPrimitive` from @base-ui/react/button
- Target: Use `@radix-ui/react-slot` for `asChild` support (same as uitripled)
- Preserve: All size variants (default, xs, sm, lg, icon, icon-xs, icon-sm, icon-lg)
- Preserve: All variant definitions
- Note: uitripled button only has 4 sizes. Add the extra sizes from current.

**input.tsx:**
- Current: Uses `InputPrimitive` from @base-ui/react/input
- Target: Pure React `<input>` element with ref forwarding
- Preserve: All styling (h-8, rounded-lg, border-input, etc.)
- Preserve: file: styling for file inputs

**separator.tsx:**
- Current: Uses `SeparatorPrimitive` from @base-ui/react/separator
- Target: Use `@radix-ui/react-separator`
- Preserve: `orientation` prop handling
- Preserve: data-slot="separator" for test compatibility
