## Interaction Contracts

### Model Config Store List Card

Layout: 5-column grid (Name, Provider, Base URL, API Key, Profiles)
- Grid: `grid gap-3 md:grid-cols-[minmax(0,1fr)_minmax(0,0.8fr)_minmax(0,1.2fr)_100px_80px]`
- Column headers: 10px uppercase semibold tracking-wide in --text-tertiary
- Column values: 13px in appropriate text color
- API Key column: 13px font-mono in --text-secondary, masked as `****1234`
- Base URL column: 13px truncated in --text-secondary
- Provider column: 13px in --text-secondary, shows `-` when empty
- Profiles column: Reuse existing profile reference count pattern (blue badges for 1-2, summary for 3+)
- Card hover: border changes to --border-hover, shadow applies --shadow-sm, translate-x 4px via Framer Motion
- Edit/Delete buttons: 14px lucide-react icons, same hover patterns as existing cards

### Model Config Editor (Create)

Layout: Single-page form following StoreComponentEditor structure
- Header: "New model config" title + Cancel + "Save" buttons
- Field order: Name -> API Key -> Base URL -> Model Name -> Provider
- Name: text input, required, placeholder "my-api-config"
- API Key: password-type input (masked dots), required, placeholder "Enter API key"
- Base URL: text input, required, placeholder "https://api.example.com"
- Model Name: text input, optional, label shows "Model Name (optional)", placeholder "claude-3-opus"
- Provider: text input, optional, label shows "Provider (optional)", placeholder "anthropic"
- All inputs: 13px text, --surface-base background, --border-default border, --accent-blue focus border
- Error banner: --accent-red/10 background with --accent-red/30 border, 13px text

### Model Config Editor (Edit)

- Header: "Edit {name}" title + Delete + Cancel + "Save" buttons
- Name field: hidden (immutable, per Phase 05)
- API Key: password-type input, pre-filled with masked value `****1234`
  - CRITICAL: If user does not change the masked value, omit apiKey from update body
  - If user clears and types new value, include apiKey in update body
- Delete button: --accent-red/10 background, --accent-red text, triggers DeleteConfirmDialog
- All other fields: same as create, pre-filled with existing values

### Profile Editor Model Config Dropdown

- Location: Selections section grid, occupies one panel cell alongside Agents/Skills/Commands/Plugins pickers
- Label: "MODEL CONFIG" (11px uppercase tracking-wide --text-tertiary)
- Control: Native `<select>` element (matching existing typeFilter select in StoreComponentList)
- Options: "None" (value "") at top, then model config names alphabetically
- Styling: rounded-[var(--radius-md)] border-[var(--border-default)] bg-[var(--surface-base)] px-3 py-2 text-[13px] text-[var(--text-primary)] focus:border-[var(--accent-blue)]
- State: bound to profile.modelConfig (optional string); selecting "None" sets to undefined
- Save behavior: modelConfig included in both CreateProfileBody and UpdateProfileBody

### Profile Detail Model Config Badge

- Location: Components section, after Plugins ComponentGroup
- Label: "Model Config" (13px font-medium --text-primary)
- When assigned: clickable badge showing config name
  - Badge style: inline-block rounded bg-white/[0.04] px-2 py-0.5 text-[12px] --text-secondary border --border-default
  - Below badge: secondary detail line showing provider + masked key in 12px --text-tertiary
    - Format: `{provider} | ****{last4} | {baseUrl}` (only show non-empty fields)
  - Click behavior: navigates to model config in store view (Claude's discretion on implementation)
- When unassigned: "No model config selected" (12px --text-tertiary)

### Delete Protection Flow

1. User clicks trash icon on model config card
2. `handleDelete` called with `force: false`
3. Backend returns 409 with `referencedBy: string[]`
4. DeleteConfirmDialog opens showing amber warning box with profile names
5. User can click "Delete anyway?" (force: true) or "Cancel"
6. Existing DeleteConfirmDialog component reused without modification

## Animation

All animations follow the existing Framer Motion patterns:

| Element | Animation | Duration | Easing |
|---------|-----------|----------|--------|
| Card entrance | opacity 0->1, x -20->0 | 200ms + staggered 30ms delay | ease-out |

## States

### Loading State
- Store list: `<Loader2 size={20} className="animate-spin text-[var(--text-tertiary)]" />` centered in py-20 container
- Profile editor dropdown: "Loading..." text in 13px --text-tertiary (matching ComponentPicker pattern)

### Empty State
- Store list (no configs): motion.div with "No model configs yet" heading + "Create a model config to define an API connection preset for your profiles." body + "New Model Config" CTA button (accent-blue)

### Error State
- Form errors: --accent-red/10 background banner at top of form, 13px text
- Field errors: inline below field in 12px --accent-red text
- API errors: same banner pattern, message from err.message

### Disabled State
- Save button while saving: opacity-50, cursor-not-allowed, text changes to "Saving..."
- Name field when editing: hidden entirely (not disabled input)
- All disabled elements: opacity 0.5, cursor not-allowed (from globals.css)
