  <action>Create `packages/cli/src/__tests__/package.test.ts` with Vitest tests that verify the package is correctly configured for publication. These tests read package.json and check the filesystem -- they do NOT depend on a running server.

The test file must contain the following test cases in a `describe('Package configuration', ...)` block:

**Test 1: "bin.cu points to dist/index.js"**
- Read `package.json`
- Assert `pkg.bin.cu === 'dist/index.js'`

**Test 2: "files field is an allowlist with dist and README.md"**
- Assert `pkg.files` is an array
- Assert it contains `'dist'` and `'README.md'`
- Assert the array length is exactly 2

**Test 3: "prepublishOnly script is configured"**
- Assert `pkg.scripts.prepublishOnly` equals `'node scripts/prepublish.mjs'`

**Test 4: "publishConfig is set for public access"**
- Assert `pkg.publishConfig.access === 'public'`
- Assert `pkg.publishConfig.registry === 'https://registry.npmjs.org/'`

**Test 5: "workspace name is preserved as @claudeui/cli"**
- Assert `pkg.name === '@claudeui/cli'`
- This confirms D-03 -- the internal name is not changed

**Test 6: "noExternal list in tsup config covers all runtime dependencies"**
- Read `packages/cli/tsup.config.ts` as text (use `readFileSync`)
- For each of the 9 dependency names (from package.json dependencies keys): @claudeui/shared, @fastify/static, cac, fastify, get-port, gray-matter, open, proper-lockfile, zod-to-json-schema
- Assert the tsup config text contains each dependency name

**Test 7: "dist/index.js exists after build"** (skip if no dist -- this test documents the expectation)
- Use `existsSync` to check `packages/cli/dist/index.js`
- If it does not exist, skip with `it.skip` and message "Run pnpm build:full first"
- If it exists, assert file size > 0

**Test 8: "dist/index.js has no external npm package imports"** (skip if no dist)
- Read `dist/index.js` as text
- Use regex to find import patterns: `from 'X'` or `from "X"` where X does not start with `node:` or `./` or `../`
- Assert that no bare npm package specifiers exist (this proves all deps are bundled)
- Pattern: `/(?<=from\s['"])(?!node:|\.\/|\.\.\/)[^'"]+(?=['"])/g`
- Assert the matches array is empty

**Test 9: "dist/ui/index.html exists after build"** (skip if no dist)
- Use `existsSync` to check `packages/cli/dist/ui/index.html`
- If it does not exist, skip with message

After writing the tests, run `cd ./packages/cli && pnpm build:full && pnpm test` to verify all tests pass.

If tests 7-9 fail because dist doesn't exist, run `pnpm build:full` first, then re-run tests.

Also run: `cd ./packages/cli && npm pack --dry-run 2>&1 | head -30` to capture the tarball contents for reference. Verify the output lists `dist/` and `README.md` but NOT `src/`, `tsup.config.ts`, `vitest.config.ts`, `.npmrc`, or `scripts/`.
</action>
