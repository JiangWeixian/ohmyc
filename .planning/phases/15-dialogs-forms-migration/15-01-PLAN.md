Per D-01, D-03: Migrate all dialogs to use NativeDialog. Each dialog keeps its existing props interface. Internal implementation swaps hand-rolled backdrop to NativeDialogOverlay + NativeDialogContent.

**Common migration pattern for ALL dialogs:**
- Remove the outer `fixed inset-0 bg-black/60 flex items-center justify-center z-50` backdrop div
- Remove `role="dialog"`, `aria-modal="true"`, `onKeyDown` for Escape (Radix handles this)
- Remove `autoFocus` (Radix handles focus management)
- Wrap content in:
  ```tsx
  import { NativeDialog, NativeDialogContent, NativeDialogTitle } from '@/components/uitripled/native-dialog';

  <NativeDialog open={true} onOpenChange={(open) => { if (!open) onCancel(); }}>
    <NativeDialogContent className="max-w-md bg-[var(--surface-raised)] border-[var(--border-default)] rounded-[var(--radius-xl)]">
      <NativeDialogTitle>...</NativeDialogTitle>
      ...content...
      <NativeDialogFooter>
        <buttons />
      </NativeDialogFooter>
    </NativeDialogContent>
  </NativeDialog>
  ```
  For dialogs with `onClose` instead of `onCancel`: use `onOpenChange={(open) => { if (!open) onClose(); }}`
- Replace bare `<button>` elements with shadcn Button from `@/components/ui/button`:
  - Cancel/secondary buttons → `<Button variant="outline" size="sm">`
  - Primary action buttons → `<Button variant="default" size="sm">`
  - Destructive buttons → `<Button variant="destructive" size="sm">`
  - Disabled buttons keep their `disabled` prop
- Import `Button` from `@/components/ui/button`
