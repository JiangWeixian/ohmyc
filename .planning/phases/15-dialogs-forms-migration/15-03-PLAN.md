- Remove the manual bg/border/focus className — shadcn Input provides proper dark theme styling

**Selections section — Model Config dropdown (per D-15):**
- Replace the bare `<select>` + `<option>` elements with shadcn Select composable:
  ```tsx
  <div className="space-y-2">
    <Label>Model Config</Label>
    {modelConfigsQ.isLoading ? (
      <span className="text-[13px] text-[var(--text-tertiary)]">Loading...</span>
    ) : (
      <Select value={modelConfig ?? ''} onValueChange={(val) => setModelConfig(val || undefined)}>
        <SelectTrigger className="w-full">
          <SelectValue placeholder="None" />
        </SelectTrigger>
        <SelectContent>
          <SelectItem value="">None</SelectItem>
          {(modelConfigsQ.data ?? []).slice().sort((a, b) => a.name.localeCompare(b.name)).map(mc => (
            <SelectItem key={mc.name} value={mc.name}>{mc.name}</SelectItem>
          ))}
        </SelectContent>
      </Select>
    )}
  </div>
  ```
- Note: `onChange={(e) => setModelConfig(e.target.value || undefined)}` becomes `onValueChange={(val) => setModelConfig(val || undefined)}`

**Runtime config section — Labels only (JsonEditor stays unchanged):**

- Keep the `className` for uppercase/tracking styling if needed, or let Label handle it
- JsonEditor components stay exactly as they are
