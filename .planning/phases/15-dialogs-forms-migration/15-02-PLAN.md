**settings/ui/Button.tsx** — Replace with thin re-export bridge:
- Remove ALL framer-motion imports and motion.button usage
- Remove whileHover, whileTap, spring animation
- Export a function `Button` that maps variant names to shadcn button variants:
  - `primary` → import and render `<ButtonNative variant="default" .../>` from `@/components/uitripled/native-button`
  - `danger` → `variant="destructive"`
  - `secondary` → `variant="outline"`
  - `ghost` → `variant="ghost"`
- Map sizes: `sm` → `size="sm"`, `md` → `size="default"`, `lg` → `size="lg"`
- Pass through `loading` prop (NativeButton supports it per D-07)
- Pass through `icon` prop as children before main children
- Pass through `disabled`, `className`, `onClick`, and all other props
- Keep the same exported function name `Button` for backward compat

**settings/ui/Input.tsx** — Replace with thin wrapper:
- Remove ALL framer-motion imports (motion.input, motion.div, motion.span)
- Remove whileFocus, initial/animate on icon, error animation
- Import shadcn `Input` from `@/components/ui/input`
- Import `Label` from `@/components/ui/label`
- Keep the wrapper structure: Label + Input + error message
- The wrapper accepts `{ label?: string, error?: string, icon?: ReactNode, ...inputProps }`
- Render: `<div className="flex flex-col gap-1.5">` → optional `<Label>` → `<div className="relative">` → optional icon → shadcn `<Input>` → optional error `<span>`
- Map className props to match current visual appearance (bg, border, focus ring colors using CSS variables)

**settings/ui/Select.tsx** — Replace with thin wrapper:
- Remove ALL framer-motion imports (motion.button, motion.div, AnimatePresence, motion.span)
- Remove all spring animations, stagger delays
- Import shadcn Select components: `Select, SelectTrigger, SelectContent, SelectItem, SelectValue` from `@/components/ui/select`
- Import `Label` from `@/components/ui/label`
- Keep the `{ label, options, error, ...selectProps }` API
- Implementation:
  ```tsx
  <div className="flex flex-col gap-1.5">
    {label && <Label>{label}</Label>}
    <Select value={props.value} onValueChange={(val) => {
      props.onChange?.({ target: { value: val } } as any);
    }}>
      <SelectTrigger className="w-full">
        <SelectValue placeholder="Select..." />
      </SelectTrigger>
      <SelectContent>
        {options.map(opt => (
          <SelectItem key={opt.value} value={opt.value}>{opt.label}</SelectItem>
        ))}
      </SelectContent>
    </Select>
    {error && <span className="text-[12px] text-[var(--accent-red)]">{error}</span>}
  </div>
  ```
- Pass through className for custom styling

**settings/ui/Toggle.tsx** — Replace with thin wrapper:
- Remove ALL framer-motion imports
- Remove motion.button, motion.span, spring animations
- Import shadcn `Switch` from `@/components/ui/switch`
- Keep the `{ checked, onChange, label, description }` API
- Implementation:
  ```tsx
  <div className="flex items-start gap-3">
    <Switch checked={checked} onCheckedChange={onChange} />

        {label && <label className="text-[13px] font-medium text-[var(--text-primary)] cursor-pointer" onClick={() => onChange(!checked)}>{label}</label>}
        {description && <span className="text-[12px] text-[var(--text-tertiary)]">{description}</span>}
      </div>
    )}
  </div>
  ```
