<decisions>
## Implementation Decisions

### Header Architecture
- **D-01:** Single shared Header component at App level. All routes get identical chrome automatically. Views render their content below the shared header.
- **D-02:** Header contains three pieces in order (right to left): secondary actions/notifications → ⌘K pill → active-profile chip. Routes are NOT allowed to render their own header search inputs or ad-hoc identity widgets.

### Active-Profile Chip
- **D-03:** Chip uses the existing `useProfiles` hook independently. No new context or prop drilling needed. The hook already returns `{profiles, active}` and updates reactively on mutations.
- **D-04:** Chip placement: top-right of shared header, on every route. Anatomy: `[avatar dot] Active <name> ▾`. Click opens dropdown with profile list + Compare + Manage profiles link.
- **D-05:** Empty state: if no active profile, show "No active profile" in text-tertiary without avatar dot. Clicking still opens dropdown.

### Command Palette (⌘K)
- **D-06:** Replace existing CommandPaletteProvider trigger with header pill. The pill is the sole visual trigger: `[search icon 14] Search... [⌘K]`.
- **D-07:** Global ⌘K keyboard listener remains active. The palette opens via keyboard or clicking the pill.
- **D-08:** The palette is visually a search input but behaviorally a button. Width: w-60 (240px), height: h-9 (36px). Right-aligned ⌘K keycap in text-quaternary.
- **D-09:** Palette opens as a centered dialog at Level 4 elevation (640px wide, max-height 480px, backdrop dim rgba(0,0,0,0.6)).

### Compare Panel
- **D-10:** Compare panel state is local to ProfilesView. It is NOT accessible from Explorer or Settings routes.
- **D-11:** Triggered from: (a) active-profile chip dropdown → "Compare…", (b) profile row hover → "Compare" action. Also supports `c` keyboard shortcut when on Profiles route.
- **D-12:** Panel slides in from right (w-[480px], full height, 200ms ease-in-out). Underlying view dims to rgba(0,0,0,0.4). Built on existing dialog primitive (Base UI / Radix Dialog wrapper).
- **D-13:** Body shows sectioned diff (Agents / Skills / Commands / Model configs / Settings) with leading markers: `+` (target only), `−` (active only), `=` (same).
- **D-14:** Footer: ghost "Close" button + primary "Activate <target>" button for one-click swap.

### Default Route
- **D-15:** Change wildcard fallback from `/explore/agents` to `/profiles`. Landing route is `/profiles`.
- **D-16:** `/explore` redirect stays (redirects to `/explore/agents`), but no longer the default.

### Explorer View Rules
- **D-17:** Remove multi-row skeletons (AnimatedList, CardSkeleton). Replace with a single subtle loading pulse/spinner for slow loads. Local config reads are fast enough that content should appear directly.
- **D-18:** Remove featured card variant (`featured={index === 0}`). All cards have equal weight in a uniform 2-column grid.
- **D-19:** Environment Summary rendered ONLY on Plugins tab. Remove it from Hooks, MCP, and LSP sections.

### Keyboard Shortcuts (Global, when palette closed)
- **D-20:** `⌘1 / ⌘2 / ⌘3` — activate 1st/2nd/3rd profile in sidebar order (Profiles route only).
- **D-21:** `g p` — go to Profiles, `g e` — go to Explorer, `g s` — go to Settings.
- **D-22:** `c` — open Compare panel against active profile (Profiles route only).
- **D-23:** Bindings are silent when focus is in a text input.

### the agent's Discretion
- Exact implementation of single subtle loading pulse vs spinner
- Compare panel animation timing and easing details
- Dropdown positioning and styling for active-profile chip
- Whether to keep or remove the `ViewSwitcher` from sidebar (wireframe shows it in sidebar, current code injects it as headerSlot)

</decisions>

<specifics>
## Specific Ideas

- Header component should be a new file at `packages/ui/src/components/header.tsx` or similar.
- The active-profile chip dropdown is a simple list, not a full menu. Items: profile names (clickable to activate) + separator + "Compare…" + "Manage profiles →".
- Command palette groups: Profile → Activate, Compare, Duplicate, Edit; Go to → Profiles, Explorer, Settings; Search → typed query.
- Compare panel uses existing dialog primitive. Header: "Compare — <active> vs <target>".
- For minimal loading state: a single centered spinner or pulse overlay instead of 4-card skeleton grid.
- ViewSwitcher currently injected as `headerSlot` prop into Sidebar. May need repositioning to sidebar-header area per wireframe.

</specifics>
