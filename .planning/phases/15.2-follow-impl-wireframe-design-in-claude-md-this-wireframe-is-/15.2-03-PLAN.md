   interface ProfilesSidebarProperties {

2. **Add hover-revealed QuickActions on profile rows:**
   - For each profile row (`TabsTrigger`), wrap the content area in a relative container
   - On hover, reveal a `QuickActions` cluster (right-aligned, `gap-1`):
     - `Activate` button — ghost style. If profile is not active, use primary styling. On click: call existing activation (this may need a new prop `onActivate` or rely on navigation + activation flow). 
     - Actually, looking at current code, activation happens via clicking the row which navigates to the profile. The sidebar doesn't directly activate. 
     - SIMPLER: Just add the `Compare` button on hover. Activation is still via the row click or the detail view.
   - Wait, re-reading DESIGN.md Profile row interactions:
     - "Default state: `[icon] <name>` and, if active, an `Active` badge pinned right."
     - "Hover: reveal a `QuickActions` cluster (right-aligned, `gap-1`): `Activate` (ghost, primary if not yet active), `Compare` (ghost)"
   - So we need BOTH Activate and Compare on hover.
   - For `Activate`: call a new `onActivate` prop with the profile name. Add this prop to the interface.
   - For `Compare`: call `onCompare` prop with the profile name.

3. **Restructure profile row to support hover actions:**
   The current row is a `TabsTrigger` which handles selection. We need to add buttons inside it that don't trigger selection. Use `e.stopPropagation()` or `e.preventDefault()` on button clicks.

   ```tsx
   <TabsTrigger value={value} className={cn('...')}>
     <span className="relative z-10"><User size={16} /></span>
     <span className="relative z-10 truncate">{p.name}</span>
     <span className="relative z-10 ml-auto flex items-center gap-1">
       {isActive && (
         <span className="text-[10px] font-medium text-[#f7f8f8] bg-[rgba(255,255,255,0.08)] px-1.5 py-0.5 rounded">Active</span>
       )}
       {/* Hover actions - hidden by default, shown on group-hover */}
       <span className="hidden group-hover:flex items-center gap-1">
         {!isActive && onActivate && (
           <button
             onClick={(e) => { e.stopPropagation(); onActivate(p.name) }}
             className="text-[10px] font-medium px-1.5 py-0.5 rounded bg-[rgba(255,255,255,0.08)] text-[#f7f8f8] hover:bg-[rgba(255,255,255,0.12)]"
           >
             Activate
           </button>
         )}
         {onCompare && (
           <button
             onClick={(e) => { e.stopPropagation(); onCompare(p.name) }}
             className="text-[10px] font-medium px-1.5 py-0.5 rounded border border-[rgba(255,255,255,0.08)] text-[#d0d6e0] hover:bg-[rgba(255,255,255,0.04)] hover:text-[#f7f8f8]"
           >
             Compare
           </button>
         )}
       </span>
     </span>
   </TabsTrigger>
   ```
