**Part A: Create `useGlobalKeyboardShortcuts` hook**

Create `packages/ui/src/hooks/use-keyboard-shortcuts.ts` implementing D-21, D-23.

- Import `useNavigate`, `useLocation` from `react-router-dom`
- Import `useEffect` from `react`

**Behavior:**
- Listen for `keydown` on `document`
- Track a "g" prefix state: when `g` is pressed, wait for next key within 1s
- If next key is `p`, navigate to `/profiles`
- If next key is `e`, navigate to `/explore/agents`
- If next key is `s`, navigate to `/settings` (or `/explore/settings` if that's the current route)
- Bindings are silent when focus is in a text input, textarea, or contenteditable (D-23):
  - Check `document.activeElement instanceof HTMLInputElement || document.activeElement instanceof HTMLTextAreaElement || document.activeElement?.getAttribute('contenteditable') === 'true'`
- Prevent default on matched shortcuts only
